## 概述

真实世界是模拟的——温度、光线、声音、压力都是连续变化的量。ADC（模数转换器）把这些模拟信号变成 ESP32 能理解的数字。

## 学习目标

- 理解 ADC 工作原理和分辨率
- 掌握 `analogRead()` 
- 学会用分压电路读取传感器

## 实战：电位器读取

```cpp
#define POT_PIN 34  // ADC1_CH6

void setup() {
  Serial.begin(115200);
}

void loop() {
  int val = analogRead(POT_PIN);
  float voltage = val * 3.3 / 4095.0;
  Serial.printf("ADC: %d, Voltage: %.2fV\n", val, voltage);
  delay(500);
}
```

> ESP32 ADC 分辨率 12bit（0-4095），默认参考电压 3.3V。
