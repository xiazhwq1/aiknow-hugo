## 概述

ESP32 的灵魂能力就是 WiFi。本篇教你用三种模式连接网络：Station 模式（连路由器）、AP 模式（自己当热点）、STA+AP 混合模式。

## 学习目标

- 理解 WiFi 工作模式
- 掌握 WiFi 库基本 API
- 学会处理断线重连

## 三种模式对比

| 模式 | 说明 | 用途 |
|------|------|------|
| Station (STA) | 连接现有 WiFi | IoT 设备联网 |
| Access Point (AP) | 自己当热点 | 配网、本地控制 |
| STA+AP | 两种同时 | 中继、网关 |

## 实战：Station 模式

```cpp
#include <WiFi.h>

const char* ssid = "your-ssid";
const char* password = "your-password";

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println(WiFi.localIP());
}
```

> 物料：只需 ESP32 开发板 + USB 数据线，无需额外硬件。
