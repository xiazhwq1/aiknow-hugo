## 概述

GPIO（通用输入输出）是 ESP32 最基础的外设。本篇带你从零开始——安装 Arduino IDE、配置开发板、编写第一行代码、点亮 LED。

## 学习目标

- 理解 GPIO 数字输出原理
- 掌握 `pinMode()` / `digitalWrite()` 函数
- 学会面包板接线

## 物料清单

| 元件 | 数量 |
|------|------|
| ESP32 开发板 | x1 |
| 面包板 | x1 |
| LED 发光二极管（红/绿） | x2 |
| 220Ω 限流电阻 | x2 |
| 公对公杜邦线 | x4 |

## 实战代码

```cpp
#define LED_PIN 2  // ESP32 内置 LED

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_PIN, HIGH);
  delay(1000);
  digitalWrite(LED_PIN, LOW);
  delay(1000);
}
```

> 走完这篇，你就正式踏入硬件编程的大门了。
